# xianzhushao.github.io

Personal academic homepage of **Xianzhu Shao**, built with [Hugo](https://gohugo.io) and the Hugo Blox Academic CV theme, deployed to GitHub Pages via GitHub Actions.

## Local preview

```bash
hugo server   # requires Hugo extended v0.136.5 and Go
```

## Structure

- `content/authors/admin/_index.md` — profile, bio, education, experience, awards
- `content/_index.md` — homepage sections
- `content/publication/` — one folder per paper
- `config/_default/` — site settings and navigation
- `static/uploads/resume.pdf` — CV
